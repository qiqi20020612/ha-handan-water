# 邯郸供水 v0.1.0

独立的 Home Assistant 自定义集成，可通过 HACS 自定义仓库安装。支持户号 UI 配置、多账户、按真实编号分别发现水表、每日及手动刷新，提供实际抄表读数、区间用量、账单应收、欠费、预存余额与缴费信息。

使用原生 Recorder 外部统计，按实际抄表日期导入每表稀疏累计水量及账单应收，适配能源面板水资源与独立费用统计。重复刷新、恢复同步及重启不重复累计；抄表修订、回退、补发歧义和已有统计冲突会暂停受影响序列。

修复 Recorder 同步故障影响读数可用性的问题：有效供水数据在 Recorder 临时读写失败、超时或提交未确认时继续显示，同步诊断保留失败信息。真实抄表及已有历史冲突保护保持生效，历史账本格式和幂等导入逻辑未改动。

修复设备关联的 `via_device` 弃用警告，改用真实父设备注册 ID 和 `via_device_id`。在加载实体平台之前注册账户设备，沿用已有设备 ID、自定义名称和实体标识；多账户及新发现水表的归属保持独立。

## 验证

- HA 2026.10.0、2026.10.1、2026.10.2：每版 78 项完整测试通过，包含真实 SQLite Recorder；2026.10.2 覆盖率 93%。
- CI 包含三版本矩阵、Ruff、公开文件隐私边界检查、Hassfest、HACS 校验及发布候选包；发布前须确认目标提交全部通过。
- 安装包仅含集成、文档、图标及元数据，附 SHA256SUMS；公开测试为可重建的合成数据。

## 安装与已知限制

在 HACS 添加 `https://github.com/qiqi20020612/ha-handan-water`，类别选“集成”；下载并重启后，在设备与服务添加“邯郸供水”。手动安装时只复制 ZIP 内 `custom_components/handan_water` 目录。能源配置和恢复说明见 README。

接口 HTTPS 探测曾超时；允许 HTTP 前须明确同意户号及返回资料的明文传输风险。仅验证过一次授权账户无需微信认证，不能保证其他账户或未来策略。所有供水 API 调用只读，不提供缴费、充值或资料修改。

源站只提供约双月抄表数据和滚动一年窗口，无法还原实际每日用量；水费统计为账单应收，并非现金缴费。实际 HACS 安装/升级、其他账户、新账单、真实换表及非 SQLite 数据库仍需对应环境验收。详见验证记录。
